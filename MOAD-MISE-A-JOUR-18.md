# Résultats évaluation HAS

Nouvelle page nationale « Résultats évaluation HAS », placée après Liste FINESS, utilisant la même table d’accès et les mêmes règles de validation des profils. Les données sont stockées dans DONNEES_PUBLIQUES, source has-essms : aucune table métier ni page de données supplémentaire n’est créée.

L’import associe le fichier officiel open_data_par_essms.xlsx (niveau A à D et indicateurs) à open_data_par_eval.xlsx (cotations du rapport / Qualiscope) par eval_code. Le dictionnaire de variables officiel fournit les libellés des critères impératifs. Les trois ressources sont publiées par la HAS sur data.gouv.fr sous Licence Ouverte 2.0. Les numéros FINESS sont rapprochés exactement du catalogue du Groupe UGECAM, sans déduction depuis le nom. La lettre de qualité et les nombres de critères atteints ne sont jamais recalculés. Une ligne correspond à un FINESS, même si plusieurs services locaux partagent ce FINESS. Les évaluations multi-ESSMS et leurs autres membres du Groupe sont signalés.

Sources : https://www.data.gouv.fr/datasets/resultats-devaluation-des-etablissements-et-services-sociaux-et-medico-sociaux-essms ; ressources HAS https://minio.data.has-sante.fr/synae/data/prod/open_data/open_data_par_essms.xlsx et https://minio.data.has-sante.fr/synae/data/prod/open_data/open_data_par_eval.xlsx ; dictionnaire https://minio.data.has-sante.fr/synae/data/prod/open_data/dictionnaire_variables.xlsx .

La date de clôture technique correspond à la date affichée sur l’exemple Qualiscope Alouette ; les dates de visite restent présentées séparément. Les anciennes cotations recalculées restent identifiées comme telles si un ancien flux est consulté. Une cotation absente n’est pas transformée en zéro. L’absence dans l’extraction n’est pas présentée comme absence d’évaluation. Aucune comparaison moyenne ni classement entre structures n’est construit.

Le propriétaire dispose d’un bouton d’actualisation HAS uniquement. L’adaptateur du collecteur public est enrichi pour joindre les deux fichiers lors des prochaines extractions quotidiennes. Une nouvelle URL Liste FINESS emploie le planificateur protégeant les données HAS contre un flux plus ancien ou privé des cotations du rapport ; toutes les anciennes URL restent immuables. Les actualisations HAS sont journalisées avec les actions inverses. Les jeux invalides ou trop anciens sont refusés.

La livraison R18, fondée sur R17, importe la source du 25 novembre 2026 : 133 FINESS, 116 démarches distinctes. Tous les champs existants des sites, contacts et questionnaires restent inchangés ; les autres sources publiques ne sont pas actualisées dans cette migration. Schéma et ACL inchangés, aucune modification des anciens widgets. Contrôles moteur sur les données et les projections, tests DOM avec API simulée pour propriétaire, éditeur validé et compte non validé, filtres, source ancienne, intégrité et limites de la transaction. Pas de test sur une session serveur utilisateur.
