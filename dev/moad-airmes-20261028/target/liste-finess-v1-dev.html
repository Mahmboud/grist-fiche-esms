Administration — importer les deux fichiers FINESS

Importez les CSV officiels. Les établissements du groupe sont sélectionnés avec les FINESS juridiques de la table UGECAM. Les autres établissements nationaux ne sont pas conservés. Les anciens enregistrements absents du nouvel import sont signalés et conservés.

Ces anciens flux sont figés aux données du 4 mai 2026. Le millésime de chaque fichier est conservé. Les capacités sont totalisées uniquement sur les lignes actives et non ambiguës ; la date de création n’est pas remplacée par la date d’ouverture. Les champs complémentaires restent disponibles pour les évolutions futures.
