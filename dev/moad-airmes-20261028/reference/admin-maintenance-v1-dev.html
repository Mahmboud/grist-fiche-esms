📗 Sauvegarde Excel Autodiag

Crée un seul fichier .xlsx contenant les réponses, l’historique et le référentiel des questions. C’est le format recommandé pour transférer l’Autodiag vers une autre version.

📥 Importer / restaurer Autodiag depuis Excel

Importe un fichier Autodiag.xlsx. Les réponses compatibles sont restaurées par couple UGECAM + site et l’historique est remappé sur les bons sites. Le référentiel de la version cible n’est pas remplacé.
